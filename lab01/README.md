# Laboratory

## Lab 1 — Building Your Deep Learning Workbench

## Objective
In this lab, I set up a complete deep learning workspace in Google Colab, connected it to GitHub for version control, and ran a Hugging Face model using PyTorch to understand the end-to-end workflow for experimentation and reporting.

## Tools Used
- Python
- Google Colab
- PyTorch
- GitHub
- Hugging Face

## Colab Link
https://colab.research.google.com/drive/1b3gxNPeWqVYpLqJeuqUuNuQNXXkkyl7O

## Model Used
`distilbert-base-uncased-finetuned-sst-2-english`

## Main Result
The model ran successfully in Colab and produced outputs as expected, confirming that the environment setup, dependencies, and inference pipeline were working correctly.

## Interesting Failure
One notable failure case happened when the input text was ambiguous or lacked context, which caused the model to return an incorrect or overconfident prediction.
